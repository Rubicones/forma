# Forma Studio

Локальный стенд для сборки квадратных рекламных креативов. Требуется Node.js 22.9 или новее.

## Запуск

Из папки проекта выполните `npm ci` при первой установке, затем `npm start`. Откройте http://127.0.0.1:4317. Рядом на порту 4318 запускается изолированный предпросмотр.

## Форматы и плеер

В брифе отметьте нужные форматы (1:1, 4:5, 9:16, 16:9, 5:4, 1.91:1) и длительность. Модель пишет один адаптивный документ, который перестраивает композицию под каждый формат с учётом безопасных зон площадок. Над предпросмотром есть переключатель форматов: ролик продолжается с того же момента. Ниже — пауза и перемотка. Анимация покадровая (`window.renderFrame(t)`), поэтому перемотка и переключение точны.

## Журнал и живой предпросмотр

Под предпросмотром ведётся журнал каждой сборки: загрузка материалов, какие файлы читает модель, ход размышлений, запросы к OpenRouter (модель, промпт, время, стоимость), статусы видео и итог с токенами. Пока модель пишет HTML, в предпросмотре обновляется черновик, сгенерированные изображения и видео показываются сразу, сценарий печатается прямо в поле, эскизы стилей появляются по мере готовности. Те же события выводятся в терминал сервера.

## Правки в чате

Под предпросмотром — чат правок для открытого креатива, нового или из истории. Напишите, что изменить, приложите скриншот (можно вставить через ⌘V или перетащить) или новые картинки на замену. Claude правит рабочую копию точечно, инструментом Edit, и предпросмотр обновляется после каждой правки. Codex возвращает документ целиком. Каждая правка — новая версия в истории со ссылкой на предыдущую. В модель уходит вся цепочка диалога. Можно открыть любую прошлую версию и ответвиться от неё.

## Сценарий и стили

Сценарий — только структура истории: тема, число сцен, бит каждой сцены с точным текстом и таймингом, без визуальных решений. Поэтому три стиля могут сильно отличаться медиумом, композицией и механикой движения.

## Стоимость

У каждого шага считается цена по публичным тарифам API, даже если запуск шёл через подписку: токены Claude и Codex по таблице в `pricing.mjs`, изображения и видео — по фактической стоимости из ответа OpenRouter. Итог виден в журнале, в статусе, под предпросмотром, в чате правок и в истории. Цены неизвестных моделей задаются в `PRICING_JSON`.

## История

Каждая сборка — сценарий, три стиля, креатив, включая ошибки и остановленные — сохраняется в `DATA_DIR/history/` отдельным JSON: вход (бриф, форматы, медиа, файлы), результат, сгенерированные медиа и полный журнал. Кнопка «История» в шапке открывает панель: креатив можно открыть в предпросмотре, эскизы стилей — снова выбрать, сценарий — вставить в форму, журнал — посмотреть. При первом запуске креативы, уже лежащие в `data/`, и последний бриф из браузера импортируются автоматически. Хранилище выбирается переменной `FORMA_STORE`: `file` (по умолчанию, всё в `DATA_DIR`) или `supabase` (общее облако, см. ниже).

## Облако: Supabase + Cloudflare R2

С `FORMA_STORE=supabase` несколько человек запускают Forma каждый у себя, но работают с общими кампаниями. История, кампании, проекты и индекс файлов хранятся в Supabase, файлы и журналы сборок — в закрытом бакете R2. Локальная папка данных становится кэшем: перед сборкой материалы скачиваются, после сборки новые файлы загружаются, а предпросмотр сам подтягивает недостающее из R2. Чужие запуски видны вживую («Идёт: N» в шапке). Шаги одной кампании блокируются на уровне базы, а одновременные правки не затирают друг друга. У каждой записи есть автор (`FORMA_AUTHOR`).

Полная инструкция — подготовка Supabase и R2, `.env`, выгрузка текущих данных, переключение, подключение коллеги и откат — лежит в [docs/cloud-runbook.md](docs/cloud-runbook.md). Основные команды:

- `npx supabase db push --remote` — создать таблицы (миграции в `supabase/migrations/`);
- `npm run cloud:migrate` — пробный прогон выгрузки локальных данных, `-- --apply` — выгрузка, `-- --merge-style-forks` — склеить стилевые копии кампаний в варианты;
- `npm run cloud:pull -- --out ./data-from-cloud` — скачать всё из облака в новую локальную папку.

## Генерация изображений и видео

Добавьте `OPENROUTER_API_KEY` в `.env`, перезапустите сервер и отметьте «Изображения» и/или «Видео» в брифе. Модель сама решает, какие кадры нужны, генерирует их через OpenRouter, открывает результат и перегенерирует при расхождении с арт-дирекшеном. Файлы сохраняются в `assets/generated/` проекта. Модели задаются в `OPENROUTER_IMAGE_MODEL` и `OPENROUTER_VIDEO_MODEL` (по умолчанию дешёвые тестовые: Nano Banana 2 Lite и Grok Imagine 1.5 Lite), лимит на сборку — в `MEDIA_MAX_IMAGES` и `MEDIA_MAX_VIDEOS`. Для Codex инструменты подключаются через локальный MCP-сервер `media-mcp.mjs`.

1. Перетащите файлы или папку с материалами. Поддерживается вложенность, до 128 МБ на файл. Для проприетарных макетов приложите экспорт в PDF, PNG или SVG, для шрифтов — веб-файлы. Произвольный бинарный формат можно загрузить, но возможность интерпретировать его зависит от Claude.
2. Заполните сценарий и визуальный стиль.
3. Выберите режим и нажмите «Собрать креатив». Деморежим использует готовую анимацию, подставляет текст и первое найденное растровое изображение. Он позволяет проверить загрузку, пути к ресурсам и предпросмотр без оплаты.
4. Для оригинальной композиции скопируйте `.env.example` в `.env`, заполните `ANTHROPIC_API_KEY`, перезапустите сервер и выберите «Генерация с Claude». SDK получает бриф, список файлов и инструмент чтения материалов. Запрос обрабатывается Anthropic. Версию модели можно задать в `CLAUDE_MODEL`. Каждый запуск создаёт отдельный проект.

## Устройство

`public/` содержит интерфейс. `creative.mjs` — промпты, `motion.mjs` — форматы и рантайм плеера, `media.mjs` — OpenRouter. `store/` — драйверы хранилища (`file`, `supabase`, тестовый `memory`), `supabase/` — миграции базы, `scripts/` — выгрузка в облако и обратно. `generator.mjs` отвечает за взаимодействие с Claude. `server.mjs` принимает материалы, сохраняет HTML и раздаёт ресурсы предпросмотра. Версии зависимостей зафиксированы в package-lock.json. Three.js и его addons доступны через import map, GSAP и Lottie подключены перед кодом креатива. Также доступны SVG, Canvas и CSS-анимация. CDN не требуется.

В `DATA_DIR` (по умолчанию data/) лежат папки проектов с assets/ и HTML. Последний макет восстанавливается в том же браузере. Бриф и стиль последней успешной сборки сохраняются в localStorage. Для будущего контейнера ставьте зависимости с npm ci на целевой платформе, монтируйте DATA_DIR на постоянный диск и передавайте ключ через окружение. HOST, PORT, PREVIEW_PORT, PREVIEW_URL и PUBLIC_HOST задаются окружением. При изменении порта предпросмотра задайте также полный PREVIEW_URL. Для публичного сервиса потребуется добавить авторизацию и разграничить доступ к материалам. Текущая версия рассчитана на одного пользователя на localhost.

Для режима Codex установите Codex CLI и задайте CODEX_API_KEY в .env (также поддерживается OPENAI_API_KEY). Ключ создаётся на https://platform.openai.com/api-keys. Если codex отсутствует в PATH сервера, задайте CODEX_BIN. Перезапустите сервер после изменения .env. Для Claude и Codex выберите модель и effort в форме. Сервер применяет настройки к конкретной сборке и показывает их рядом с результатом.

Тарифы Codex Standard проверены 16 ноября 2026 г. Оценка использует счётчики CLI. Если CLI не выделяет запись в кэш, некэшированный вход оценивается по базовой ставке. Когда суммарный вход за ход превышает 272 000 токенов, для тарификации нужны счётчики отдельных запросов, и Forma показывает неизвестную стоимость. Claude использует стоимость из Agent SDK, а при ручном тарифе использует собственный расчёт. Для отдельной ставки часовой записи в кэш можно задать `cacheWrite1h`.

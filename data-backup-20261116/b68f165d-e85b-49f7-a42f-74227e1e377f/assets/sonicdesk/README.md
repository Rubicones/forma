# sonicdesk — kit sources

Exported from the "Sonicdesk Design System" artifact (version 1792493577-8eae) for toggle2 kit intake.

- `brandbook.md` — principles, voice and vocabulary, visual foundations, logo rules
- `landing-and-ads.md` — ad and promo rules, messages, the honest feature list
- `palette.md` — colours in hex (promo `sd-*` set and the Lime app set), type summary
- `logos/app-icon.svg` — the app icon (lime pill on #0d0d0d). The wordmark has no file: it is "sonicdesk" in Archivo Bold, lowercase, tight tracking, foreground ink, closed by a lime full stop
- `fonts/` — Archivo 400/700/800, JetBrains Mono 400/500/700 (woff2, OFL)
- `references/` — product UI screenshots
- `source/` — the full token table (all 7 themes) and tokens.json, for reference

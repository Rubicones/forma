# Toggle Concepts brand pack · v1.1 · 3 November 2026

The brand book, logo files, fonts, design tokens and a filled campaign brief for Toggle Concepts.

| File | What it is |
|---|---|
| `Toggle_Concepts_Brandbook.pdf` | Visual brand book: 15 pages, 16:9 |
| `brandbook.md` | The same rules as short text, in the brand kit field order |
| `tokens.json` | Design tokens: colors, gradients, type, spacing, radius, layout, motion, ad safe areas |
| `logo/` | SVG logos in navy, white and black: wordmark, symbol, app icon, horizontal lockup, stacked lockup |
| `logo/png/` | PNG exports with transparent background, plus the glossy ring |
| `fonts/` | Inter Tight 400/500/600/700 (TTF) and its license, SIL OFL 1.1 |
| `brief/brief_filled.md` | Filled campaign brief, question by question in the form's order |
| `brief/brief.json` | The same brief in the studio schema (`briefDraftSchema` 1.0); delivery date and rights are added when the brief is sent |
| `img/` | Founder film frame and landing screenshots |

## Using the logo

- Start from the SVG files. Use the PNGs only where SVG is not supported.
- Navy logo on light backgrounds, white logo on navy, gradients and photos. Black is for one-color print only.
- Keep clear space of half the wordmark height on every side.
- Minimum width: wordmark 64 px, lockup 120 px.
